# MarketMind Intelligence 2.0

**An AI-Powered Business Intelligence & Customer Analytics Platform**

🔗 **[Live Demo](https://marketmind2-0-intelligence.onrender.com/)**
URL : https://marketmind2-0-intelligence.onrender.com/

## Overview

MarketMind Intelligence 2.0 is a machine learning-based platform designed to help businesses analyze customer feedback, forecast product demand, and optimize inventory decisions through an interactive dashboard.

The project aims to make data-driven business insights accessible and actionable.

## Key Features

- **Dashboard:** Visualizes business metrics and customer sentiment insights.
- **Customer Intelligence V2:** Performs sentiment analysis, aspect-based review analysis, and rating–review mismatch detection.
- **Demand Intelligence:** Predicts future product demand using machine learning.
- **Inventory Intelligence:** Analyzes stock levels and provides restocking recommendations.

## Tech Stack

- **Python** — Core development
- **Scikit-learn & TF-IDF** — Machine learning and text analysis
- **Pandas & NumPy** — Data processing
- **Gradio** — Interactive user interface
- **Render** — Cloud deployment

## Current Limitations

- Uses a predefined dataset and simulated business data rather than live company databases.
- Aspect detection uses lightweight keyword-based matching, which may miss complex customer expressions.
- Demand forecasts and inventory recommendations are experimental and require validation using real business data.
- Currently operates as a demonstration application without individual user accounts or company-specific workspaces.

## Future Enhancements

MarketMind is envisioned to evolve into a more user-friendly, personalized business intelligence platform.

- **Secure User Authentication:** Personal login and account management for individual users and organizations.
- **Dedicated Company Workspaces:** Separate dashboards where startups and businesses can manage their own data and insights.
- **Database Integration:** Connect directly with each company's databases to analyze real customer reviews, sales, and inventory records.
- **Real-Time Analytics:** Automatically update insights as new business data becomes available.
- **Enhanced AI Models:** Improve sentiment understanding, demand forecasting accuracy, and personalized business recommendations.
